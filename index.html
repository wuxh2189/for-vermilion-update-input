如何开启多人共享
  1. 创建 Supabase 项目，在 Authentication → Users 新建一个邮箱密码用户，确认邮箱并复制该用户的 User UID。
  2. 复制下面的 SQL，把 ADMIN_USER_UUID 替换为这个 UID，粘贴到 Supabase SQL Editor 并运行。
  3. 用文本编辑器找到本文件内的 SUPABASE_URL 和 SUPABASE_PUBLIC_KEY 两行，填入项目 URL 和公开的 Publishable key，然后重新上传到 GitHub Pages。管理员密码只在网页登录时输入。
  4. 打开发布后的页面。你可以登录修改正文，访客可以直接发布补充，其他人刷新即可看到。
